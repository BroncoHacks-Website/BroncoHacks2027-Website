# Backend (Spring Boot)

Simple Spring Boot structure for:
- authentication and account management
- team creation, join, and discovery APIs
- public profile APIs

Database entities and schema are intentionally deferred.


## How to set up Docker Container

The following commands must be done in the same directory   
where *docker-compose.yaml* is located.

1. "docker compose up -d" to create and run container
2. Use "docker compose ps" to check on status of container whenever
3. When done using container, use "docker compose stop" to temporarily stop
